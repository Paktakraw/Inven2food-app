# Inven2Food

เว็บแอปจัดการวัตถุดิบภายในร้านอาหาร สำหรับผู้ใช้คนเดียว ติดตามว่าซื้ออะไรมาเมื่อไร กี่บาท ปริมาณเท่าไร ทำอาหารไปเท่าไร ใช้วัตถุดิบเท่าไร เหลือเท่าไร และรายการอาหารไหนใช้วัตถุดิบอะไรบ้าง ไม่เกี่ยวกับการรับหรือจัดการรายการสั่งจากลูกค้า

ทุกอย่างที่ผู้ใช้เห็นบนหน้าจอเป็นภาษาไทยล้วน (ข้อยกเว้นมีเพียง `Inven2Food`, `Email`, `Password`)

## สถานะ

กำลังพัฒนา เสร็จแล้ว Task 1 จากทั้งหมด 13 task (โครงโปรเจกต์, ล็อกอิน, ไฟล์ข้อความไทย, ธีมมืดแบบ GitHub) งานที่ยังไม่ทำ: สคีมาฐานข้อมูล ฟังก์ชันตัดของ และหน้าจอต่าง ๆ ดูรายละเอียดที่แผนการสร้าง

## แนวคิด 4 ส่วน

1. **รายการซื้อของ:** วางแผนซื้อและจ่ายตลาด แล้ว "นำเข้าคลัง" บันทึกราคาจริง ปริมาณจริง วันหมดอายุ
2. **คลังวัตถุดิบ:** ของคงเหลือแยกเป็นรอบที่ซื้อ แต่ละรอบมีราคาทุนและวันหมดอายุของตัวเอง ใช้ของที่หมดอายุก่อน (FEFO)
3. **รายการอาหารและการทำอาหาร:** สูตรต่อ 1 จาน กด "บันทึกการทำ" แล้วระบบตัดวัตถุดิบตามสูตร คิดต้นทุน ยกเลิกได้
4. **การแจ้งเตือน:** ของใกล้หมดอายุ และของใกล้หมด

## เทคโนโลยี

Next.js (App Router) + TypeScript, Tailwind CSS, shadcn/ui, Supabase (Postgres + Auth), Vitest, Playwright, pgTAP

กฎที่แก้ยอดของคงเหลือทั้งหมดจะอยู่ในฟังก์ชัน SQL ในฐานข้อมูล หน้าเว็บไม่แก้ยอดตรง ๆ

## เริ่มใช้งานในเครื่อง

ต้องมี: Node.js, npm, Docker (เปิดไว้), Supabase CLI

```bash
npm install
npx supabase start            # เริ่มฐานข้อมูลในเครื่อง (ใช้ Docker)
npx supabase status           # ดู URL และคีย์ที่ต้องใส่ในขั้นถัดไป
cp .env.example .env.local    # แล้วกรอกค่าตามที่ status แสดง
node --env-file=.env.local scripts/create-user.mjs   # สร้างผู้ใช้ล็อกอิน (สมัครสมาชิกใหม่ปิดอยู่)
npm run dev                   # เปิด http://localhost:3000
```

ไฟล์ `.env.local` ห้าม commit ส่วน `SUPABASE_SERVICE_ROLE_KEY` ใช้เฉพาะสคริปต์และเทสต์ ห้ามนำไปใช้ในโค้ดใต้ `src/`

## คำสั่งที่ใช้บ่อย

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเว็บแบบพัฒนา |
| `npm run build` | build สำหรับใช้งานจริง |
| `npm run lint` | ตรวจสไตล์โค้ด |
| `npm test` | ทดสอบหน่วย (Vitest) |
| `npm run test:db` | ทดสอบฟังก์ชันฐานข้อมูล (pgTAP) ต้องเปิด `supabase start` ก่อน ตอนนี้ยังไม่มีเทสต์ฐานข้อมูล |
| `npm run test:e2e` | ทดสอบผ่านเบราว์เซอร์ (Playwright) ต้องเปิด `supabase start` ก่อน |
| `npx playwright test e2e/login.spec.ts` | รันเฉพาะไฟล์เทสต์เดียว |
